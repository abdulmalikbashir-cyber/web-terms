What is HTTP?

HTTP (Hypertext Transfer Protocol) is the set of rules that web browsers and servers use to communicate. It's the foundation of data exchange on the World Wide Web.

HTTPS = HTTP + SSL/TLS encryption. Always look for "https://" in your address bar – it means your connection is secure.

HTTP works as a request-response protocol between client (browser) and server.

HTTP Request Methods

  • GET: Request data from the server (e.g., loading a webpage).
  • POST: Submit data to the server (e.g., form submission).
  • PUT: Update an existing resource.
  • DELETE: Remove a resource.

Common HTTP Status Codes

  • 200 OK: The request succeeded.
  • 301 Moved Permanently: The page has moved to a new URL.
  • 403 Forbidden: Access denied.
  • 404 Not Found: The requested resource doesn't exist.
  • 500 Internal Server Error: The server encountered an error.

HTTP vs. HTTPS

HTTPS encrypts data between your browser and the server, protecting it from eavesdropping. Always use HTTPS for sensitive info like passwords or credit cards.
