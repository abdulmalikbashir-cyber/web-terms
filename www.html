What is the World Wide Web?

The World Wide Web (WWW) is an information system that enables documents and other web resources to be accessed over the internet. It was invented by British scientist Tim Berners-Lee in 1989 while working at CERN.

Key Fact: The World Wide Web is NOT the same as the internet. The internet is the global network infrastructure, while the WWW is a service that runs on top of it — a system of interlinked hypertext documents accessed via web browsers.

The WWW connects millions of web pages through hyperlinks across the globe.

How Does It Work?

The Web works through three core technologies:

  • HTML (HyperText Markup Language) — used to format and display web content.
  • URL (Uniform Resource Locator) — a unique address used to locate each web resource.
  • HTTP (HyperText Transfer Protocol) — the protocol used to transfer data between browsers and servers.

Key Characteristics

  • Uses hyperlinks to connect documents and pages across the internet.
  • Accessible through web browsers such as Chrome, Firefox, and Edge.
  • Supports multimedia content including text, images, video, and audio.
  • Operates on a client-server model — users request content, servers deliver it.
  • Content is hosted on web servers around the world.

History of the WWW

Tim Berners-Lee proposed the concept in 1989 and by 1991 the first website went live. The web evolved from static pages (Web 1.0) to interactive platforms (Web 2.0), and continues to evolve with semantic technologies and AI (Web 3.0 and Web 4.0).

Did You Know? The first ever website — info.cern.ch — was published on August 6, 1991 and it explained what the World Wide Web was.
