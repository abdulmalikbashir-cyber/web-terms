What is DNS?

DNS (Domain Name System) is often called the "phonebook of the internet." It translates human-friendly domain names (like www.google.com) into machine-readable IP addresses (like 142.250.190.46) that computers use to find each other.

Key Fact: Without DNS, you would have to remember long strings of numbers (IP addresses) for every website you want to visit.

DNS servers work behind the scenes every time you type a web address.

How DNS Works (Step by Step)

  1. You type www.example.com into your browser.
  2. Your computer asks a DNS resolver (usually provided by your ISP or a public DNS like 8.8.8.8).
  3. The resolver checks its cache; if not found, it queries root name servers.
  4. Root servers point to Top-Level Domain (TLD) servers (e.g., .com, .org).
  5. TLD servers point to authoritative name servers for the specific domain.
  6. The authoritative server returns the IP address for example.com.
  7. Your browser then connects to that IP address and loads the website.

Types of DNS Servers

  • DNS Resolver (Recursive Resolver): Handles the client's request and does the legwork to find the IP.
  • Root Name Server: The top of the DNS hierarchy (13 logical root servers worldwide).
  • TLD Name Server: Manages domains for specific extensions (.com, .org, .uk).
  • Authoritative Name Server: The final source of truth for a domain's IP address.

Common DNS Record Types

  • A Record: Maps a domain to an IPv4 address.
  • AAAA Record: Maps a domain to an IPv6 address.
  • CNAME Record: Aliases one domain to another (e.g., www.example.com → example.com).
  • MX Record: Specifies mail servers for email delivery.
  • TXT Record: Holds text information (often for verification or security).
  • NS Record: Indicates which name servers are authoritative for the domain.

Public DNS Providers vs. ISP Default

Many people use public DNS for speed and privacy: Google DNS (8.8.8.8, 8.8.4.4), Cloudflare DNS (1.1.1.1), OpenDNS. They can be faster and more reliable than your ISP's default DNS.

DNS Security Threats

  • DNS Spoofing / Cache Poisoning: Attackers inject false DNS records to redirect users to fake sites.
  • DNS Tunneling: Hiding non-DNS traffic inside DNS queries to bypass firewalls.
  • DNSSEC (Domain Name System Security Extensions): A security protocol that signs DNS records to verify authenticity.

Without DNS, the internet as we know it would be impossible to use. It's one of the most critical but invisible components of online life.
