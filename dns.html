What is DNS?

DNS stands for Domain Name System. The easiest way I can describe it is that it works like the internet's phonebook. Just like how a phonebook maps a person's name to their phone number, DNS maps a website's name to its IP address.

Instead of having to remember a long and confusing number like 142.250.190.46, DNS lets you simply type www.google.com and it does the translation for you behind the scenes. This makes it much easier for everyday users to access websites using simple, readable names.

In simple terms: DNS translates domain names into IP addresses so that browsers can load websites. Without it, you would need to memorise long strings of numbers just to visit a website.

Every time you type a website address, DNS is working in the background to find the right IP address.

How DNS Works (Step by Step)

When you type a website address into your browser, here is what happens:

  1. You type something like www.example.com into your browser.
  2. Your computer contacts a DNS resolver — usually provided by your internet service provider or a public DNS like Google's 8.8.8.8.
  3. The resolver checks if it already knows the answer from a previous lookup (this is called the cache).
  4. If not found, it asks a root name server, which points it in the right direction.
  5. The root server sends it to a TLD (Top-Level Domain) server, like one that handles all .com addresses.
  6. The TLD server then points to the authoritative name server for that specific domain.
  7. The authoritative server finally gives back the correct IP address.
  8. Your browser uses that IP address to connect to the website and load it for you.

Types of DNS Servers

  • DNS Resolver: This is the first stop. It takes your request and does all the searching on your behalf.
  • Root Name Server: Sits at the top of the DNS hierarchy. There are 13 logical root servers around the world.
  • TLD Name Server: Handles domains based on their extension — like .com, .org, or .co.ke.
  • Authoritative Name Server: The final source that holds the actual IP address for a specific domain.

Common DNS Record Types

  • A Record: Links a domain name to an IPv4 address.
  • AAAA Record: Links a domain name to an IPv6 address.
  • CNAME Record: Points one domain to another domain name.
  • MX Record: Tells the internet where to send emails for a domain.
  • TXT Record: Stores text information, often used for security verification.
  • NS Record: Tells you which name servers are in charge of a domain.

Popular Public DNS Providers

You do not have to use your internet provider's default DNS. Many people switch to public DNS servers for better speed and privacy. Some popular ones are:

  • Google DNS: 8.8.8.8 and 8.8.4.4
  • Cloudflare DNS: 1.1.1.1 — known for being very fast and privacy-focused
  • OpenDNS: Offers extra filtering and parental controls

DNS Security Threats

  • DNS Spoofing: Attackers feed fake DNS records so users get sent to the wrong website without knowing.
  • DNS Tunneling: Hiding other types of traffic inside DNS requests to sneak past firewalls.
  • DNSSEC: A security extension that digitally signs DNS records so you can trust the results are genuine.

DNS is one of those things most people never think about, but it is running every single time you go online. Without it, the internet would be almost impossible to use for normal people.
