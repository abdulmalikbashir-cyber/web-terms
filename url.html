What is a URL?

A URL (Uniform Resource Locator) is the address you type into a web browser to visit a specific webpage or file on the internet. Think of it like a street address for a house, but for websites.

Example: https://www.example.com:443/about.html

Each part of a URL tells the browser where to go and what to request.

Parts of a URL

  • Protocol: (e.g., https://) – The communication method (HTTP, HTTPS, FTP).
  • Domain name: (e.g., www.example.com) – The website's unique address.
  • Port (optional): (e.g., :443) – Technical endpoint; default for HTTPS is 443.
  • Path: (e.g., /about/contact) – Specific page or folder location.
  • Query string: (e.g., ?id=123&sort=asc) – Additional parameters for dynamic pages.
  • Fragment: (e.g., #section2) – A bookmark inside the page.

Why URLs Matter

Every resource on the web—HTML pages, images, videos, CSS files—has a unique URL. Without URLs, you couldn't directly share or find anything online.
