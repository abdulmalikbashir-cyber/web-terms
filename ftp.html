What is FTP?

FTP (File Transfer Protocol) is a standard network protocol used to transfer files between a client and a server on a computer network. It's one of the oldest internet protocols, predating the World Wide Web.

Key Fact: FTP uses two separate channels: a command channel (port 21) and a data channel (port 20) for transferring files.

FTP is commonly used for uploading website files to hosting servers.

Common Uses of FTP

  • Uploading website files (HTML, CSS, images) to a web host.
  • Downloading large files from public FTP servers (software, datasets).
  • Backing up data to remote servers automatically.
  • Sharing large files with colleagues (though less common now).

FTP Modes: Active vs. Passive

  • Active FTP: The client opens a port and the server connects to it. Can face firewall issues.
  • Passive FTP: The server tells the client which port to connect to; better for firewalls and NAT.

Security: FTP vs. SFTP vs. FTPS

  • FTP: No encryption – passwords and files are sent in plain text. NOT secure.
  • FTPS (FTP Secure): Adds SSL/TLS encryption to FTP.
  • SFTP (SSH File Transfer Protocol): A completely different, secure protocol over SSH (port 22).

Today, for security, you should use SFTP or FTPS instead of plain FTP, especially when transferring sensitive data.
