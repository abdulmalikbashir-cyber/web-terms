What is an Extranet?

An extranet is a controlled private network that allows external partners, suppliers, vendors, or customers to access specific parts of an organization's intranet. It's like giving a key to trusted outsiders.

Key Difference: Intranet = internal only. Extranet = internal + select external users.

Extranets enable secure collaboration with outside partners.

Common Uses of an Extranet

  • Supply chain management portals (suppliers check inventory).
  • Customer support systems (clients submit tickets).
  • Partner collaboration platforms (share documents securely).
  • Vendor portals (submit invoices, track orders).
  • Distributor price lists and ordering systems.

Security Measures for Extranets

  • Firewalls: Restrict access to only authorized external IPs.
  • VPN (Virtual Private Network): Encrypted tunnel for remote users.
  • Two-Factor Authentication (2FA): Extra login verification.
  • Role-based access control (RBAC): Partners see only what they need.

Real-World Example

Walmart uses an extranet to connect with thousands of suppliers. Suppliers log in to check demand forecasts, submit shipping notices, and invoice Walmart – all without accessing Walmart's internal employee systems.
