What is HTML?

HTML (Hypertext Markup Language) is the standard markup language used to create and design web pages. It provides the structure and content of a webpage, such as headings, paragraphs, links, images, and more.

Key Fact: HTML is not a programming language — it's a markup language. It tells the browser how to display content, not how to perform logic.

HTML uses elements enclosed in angle brackets (tags) like <h1> for headings.

Basic HTML Structure

  • <!DOCTYPE html> – Declares the document type (HTML5).
  • <html> – The root element of the page.
  • <head> – Contains meta-information (title, CSS, scripts).
  • <title> – The page title shown in the browser tab.
  • <body> – Contains all visible content (headings, text, images).

Common HTML Tags

  • <h1> to <h6> – Headings (h1 is most important).
  • <p> – Paragraph of text.
  • <a href="url"> – Hyperlink to another page.
  • <img src="image.jpg"> – Embed an image.
  • <ul>, <ol>, <li> – Unordered/ordered lists.
  • <div> and <span> – Containers for styling and layout.

Why HTML Matters

Every website you visit — from Google to Wikipedia to this page — is built with HTML. Along with CSS (styling) and JavaScript (interactivity), HTML is the foundation of the World Wide Web.
